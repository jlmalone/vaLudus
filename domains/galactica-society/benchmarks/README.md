# Galactica society benchmarks

The first executable benchmark is the
[synthetic provenance-label counterfactual](provenance-label/README.md). It tests whether a fixed
information-governance intervention meets declared benefit, distributional, and neutral-reach
thresholds across 200 paired worlds.

Further benchmarks should remain narrow: maintain essential supply through a shock, allocate a
constrained resource without violating stated rules, recover from an agent failure, and explain a
decision with evidence. Aggregate output alone is insufficient. Distributional harm, rule
violations, and recoverability are first-class outcomes.
