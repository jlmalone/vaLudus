# Galactica society generator

The Kotlin reference kernel currently generates synthetic people with resource position,
employment, income, savings, interests, media literacy, susceptibility, institutional trust,
social conformity, and initial belief state. Each person accumulates work, media, and leisure time,
resource shortfalls, exposures, belief, and resharing outcomes.

These distributions and transition coefficients are hypotheses in kernel version `0.1.0`. They
are not calibrated representations of a real population. Additional generators should use
versioned world specifications, preserve stable synthetic identities inside a run, and generate
held-out scenarios only after candidate policy and prompt configurations are frozen.
