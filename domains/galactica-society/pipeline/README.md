# Galactica society pipeline

The first pipeline runs seeded, paired counterfactual simulations. A baseline and intervention use
the same generated population and random stream. The runner writes the exact plan, daily metrics,
individual outcomes, paired replication effects, evidence hashes, resource observations, and a
run report.

The current kernel evaluates one fixed provenance-label intervention. Future candidate policy
agents must sit behind an isolated adapter and choose only from declared policy powers. The trusted
kernel continues to resolve effects and score results. Simulator decisions must never transfer to
a real system.

The sensitivity runner executes one-factor perturbations through the same kernel and retains each
configuration as a complete child run. Its aggregate report is a manifest of those reports, not a
replacement for their evidence. The first competing dynamics are linear persuasion and log-odds
evidence accumulation; neither is treated as a validated theory of belief.
