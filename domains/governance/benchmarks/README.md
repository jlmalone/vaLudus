# Governance charter-conformance benchmark

This benchmark family measures a narrow claim: whether a system can apply supplied synthetic authority and control rules to one proposal. It does not establish judgment, institutional legitimacy, legal compliance, or suitability for real-world governance.

Every evaluation must report:

- the generated manifest, seed custody, and release timing;
- prompt and adapter configuration separately from the charter fixture;
- exact structured decision and reason failures by partition;
- token, cost, wall-time, and memory observations; and
- contamination risks, including public exposure to the fixture grammar.

Add new fixture families only when the expected result can be deterministically derived from an inspectable synthetic charter. Questions requiring normative or legal judgment need a separately governed protocol and must not be silently converted into an answer key.
