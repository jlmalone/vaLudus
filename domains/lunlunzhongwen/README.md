# LunLunZhongWen domain

LunLunZhongWen is an instructional-content generation domain. It evaluates whether an agent can
turn a bounded learner request into a correct, usable Chinese character or vocabulary lesson while
preserving factual, linguistic, and rendering evidence.

See [pipeline](pipeline/README.md), [generator](generator/README.md), and
[benchmarks](benchmarks/README.md).
